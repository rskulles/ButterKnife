# Contributing

Thanks for taking an interest in ButterKnife. The short version: **bug reports are very welcome, pull requests are not.**

## Bug reports, ideas and questions: yes please

- **Bug reports.** If something breaks, open an issue with what you did, what you expected, and what happened instead.
  Include the backend you were talking to (Ollama, LM Studio, and so on) and the browser. I read every one, and a good
  report is the most useful thing anyone can send this project.
- **Ideas.** Feature suggestions are welcome as issues. I may not build them, but I like hearing how people use it.
- **Questions** about setup or about the licence. If you'd like to use ButterKnife commercially, an issue is the right place to ask.

## Pull requests: no, but kindly

ButterKnife is a personal project, and I'd like to keep it that way. It's built the way I want it, at the pace I want,
and I'm not looking to grow a contributor base or review outside code. **Pull requests will be closed without review.**
That isn't a comment on your work, and I don't want anyone to spend an evening on a change only to have it turned away.

There's also a practical reason. The project is [source-available under the PolyForm Noncommercial License](LICENSE.md),
and accepting code from other people would complicate the copyright that licence depends on.

## Making it your own

The licence lets you fork, modify and run ButterKnife for any noncommercial purpose. If the project doesn't do what you
want, the source is right there, and you don't need my permission to change your own copy. Go make it yours.

Thanks for understanding, and enjoy the app.
